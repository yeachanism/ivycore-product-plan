# Ivycore 제품 기획 v0.2

학생·학부모·선생님·어드민을 연결하는 IB 학습 서비스의 제품 기획 개정본입니다.

[HTML 기획 문서 읽기](https://yeachanism.github.io/ivycore-product-plan/)

[Markdown 원본 읽기](./ivycore-product-plan-v0.2.md)

기존 17개 항목과 역할별 흐름을 유지하면서 학습 판단 기준, 검수된 학습 자료, 품질 책임, 상품·지원 범위, 파일럿 검증과 데이터·상태 규칙을 보완했습니다. Economics 학습 주기 설계 예시, 24개 출시 검증 시나리오, 12개 운영 전 결정 항목을 포함합니다.

## 파일

- `index.html`: GitHub Pages에 배포되는 단일 HTML 문서. 모바일 목차, 검색, 접기·펼치기, 인쇄와 Markdown 저장 기능을 제공합니다.
- `ivycore-product-plan-v0.2.md`: 편집·검토용 Markdown 원본.
- `ivycore-product-plan-v0.1.html`: 최초 배포 커밋의 HTML을 바이트 변경 없이 보관한 v0.1 원본.
- `ivycore-product-plan-v0.1.md`: v0.1 HTML 본문을 내용 변경 없이 변환한 읽기·비교용 Markdown 보관본.
- `.nojekyll`: 저장소 파일을 정적으로 제공하기 위한 기존 설정.

GitHub Pages는 `main` 브랜치 루트를 제공합니다. HTML은 브라우저에서 직접 열어도 읽을 수 있으며, 외부 라이브러리나 빌드 과정이 필요하지 않습니다. v0.2 HTML 내부의 Markdown 저장용 원문과 `ivycore-product-plan-v0.2.md`는 동일한 내용으로 유지합니다.
